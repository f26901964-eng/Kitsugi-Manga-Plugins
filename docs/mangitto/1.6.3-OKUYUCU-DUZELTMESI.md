# Mangitto 1.6.3 — kaybolan mangaSlug

Kullanıcının Chainsaw Man Bölüm 1 ekranında gösterdiği hata:
`Key mangaSlug is missing in the map.`

Önceki kaynak `chapter.memo.getString("mangaSlug")` çağrısını görsel isteğinden
önce yapıyordu. Uygulama yalnız bölüm URL'sini saklayıp memo bilgisini
iletmediğinde bu çağrı hata veriyordu. Uygulamadaki tam veri kaybı noktası bu
depoda doğrulanmadı; fakat kaynakta memo bağımlılığı ve hata yolu kaldırıldı.

Yeni bölüm kayıtları `/manga/chainsaw-man/1` gibi kendi başına yeterli URL taşır.
Hem okuyucu URL'si hem API hem CDN fallback istekleri aynı ayrıştırılmış seri
ve bölüm numarasını kullanır. Eski sayısal URL + memo biçimi desteklenir.
Yalnız `1` gibi URL kalmış ve memo kaybolmuş eski kayıtta seri tahmin edilmez;
seri sayfasından bölüm listesini yenileme yönlendirmesi yapılır.

GitHub testi ve imzalı APK derlemesi başarılı:
https://github.com/f26901964-eng/Kitsugi-Manga-Plugins/actions/runs/42212843719

Altı regresyon testi: memo olmadan URL kalıcılığı, 0.01 bölümü, tam/kısa
adresler, eski memo desteği, kurtarılamayan eski kayıt, geçersiz bölüm numarası.
Mevcut HTML testleri de çalıştırıldı. Python: 26 geçti, 12 atlandı.
Sürüm 1.6.3 / 106003. Cihaz içi okuma ve canlı CDN erişimi doğrulanmadı.

Güncellemeden sonra eski bölüm kaydı önbellekteyse seri detayını açıp bölüm
listesini yenileyin, ardından bölümü yeniden seçin. Güncellemeyi kurmak tek
başına uygulamadaki eski sayısal bölüm kayıtlarını değiştirmez.
